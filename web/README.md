# RLForge website

The marketing and explainer site for RLForge. Next.js 14 (app router),
TypeScript and Tailwind. Runtime dependencies: `next`, `react`, `react-dom`.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # vitest: GridWorld port, diamond graph, version guard, test counts
npm run build
```

## Deploying on Vercel

| Setting | Value |
|---|---|
| Framework preset | Next.js |
| Root directory | `web` |
| Build / install / output | defaults (`next build`, `npm install`, `.next`) |
| Node.js | 18.17+ (20.x recommended) |

Optional environment variables:

- `GITHUB_TOKEN`: a read-only token. It raises the GitHub API rate limit for
  the star/fork counts. Without it the site uses unauthenticated requests
  (60/hour per IP), which is enough with hourly caching.
- `NEXT_PUBLIC_SITE_URL`: canonical URL for OpenGraph tags. On Vercel it
  defaults to the production domain.

## Where the numbers come from

Every number on the page is traceable: look for a `// file:line` comment next
to it, or a visible `↳ source` link.

- `lib/content.ts`: test counts, milestones, docs, deferrals.
  `tests/test_count.test.ts` re-counts the `TEST_CASE`s in `../tests` and
  fails if the site drifts from the C++ suite.
- `lib/gridworld.ts` + `lib/mt19937.ts`: a TypeScript port of GridWorld,
  SyncVectorEnvironment, TabularQLearningAgent and Trainer, configured as in
  `tests/test_trainer_grid_world.cpp`. It is not the C++ library running in
  the browser. `scripts/parity/` has a native harness, and
  `tests/gridworld.test.ts` checks the port against its output checkpoint for
  checkpoint.
- `lib/diamond.ts`, `lib/versionGuard.ts`: the math behind the diamond-bug
  and version-guard widgets, checked in `tests/`.

## Live GitHub data

`lib/github.ts` fetches stars, forks and license from the GitHub API with a
one-hour revalidate (ISR). The page hydrates with those values and refreshes
once from `/api/repo`. If GitHub can't be reached, no count is shown. The
footer links a LICENSE file only when GitHub detects one.

## Motion

Scroll reveals, the GridWorld loop, the diamond animation, the count-up and
the ember pulse all pause when off-screen or when the tab is hidden. Under
`prefers-reduced-motion: reduce` nothing autoplays, and every widget can
still be stepped by hand.

## Icons

`app/icon.svg` is the source mark. `app/favicon.ico` (16/32/48) and
`app/apple-icon.png` (180×180, full-bleed) were rendered from it. The
OpenGraph image is generated by `app/opengraph-image.tsx`.
